PHÒNG
YouTube Data API key (chỉ dùng để tìm bài; lưu trong trình duyệt này)
Lấy key: Google Cloud Console → bật YouTube Data API v3 → Credentials → Create API key (nên giới hạn theo HTTP referrer và theo API).
Hạn mức mặc định 10.000 đơn vị/ngày, mỗi lượt tìm tốn 100 đơn vị (≈ 100 lượt tìm/ngày). Kết quả đã tìm được lưu tạm để không tốn thêm.
