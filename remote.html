PHÒNG
YouTube Data API key (chỉ dùng để tìm bài và đọc thông tin video; lưu trong trình duyệt này)
Lấy key: Google Cloud Console → bật YouTube Data API v3 → Credentials → Create API key (nên giới hạn theo HTTP referrer và theo API).
Hạn mức mặc định mỗi dự án: 100 lượt tìm YouTube mỗi ngày (tính riêng) và 10.000 đơn vị/ngày cho các lệnh khác. Thêm bài bằng link, nạp playlist và làm mới danh mục chỉ tốn khoảng 1 đơn vị mỗi lần. Hạn mức reset lúc nửa đêm giờ Thái Bình Dương (khoảng 14h–15h giờ Việt Nam).
